Cactus Library of Useful functions
==============================================

Dependencies
============

Packages needed to build package

- automake
- cproto
- gcc-c++
- git


Extra packages needed at run-time for certain functions:
==================================================================

Fetching:
=========

Downloaded via git:

git clone git@iplant4.arl.arizona.edu:/home/git/caclib.git


Building:
=========

- % cd caclib (the top of the distribution)
- % make proto (watch for any 'red' errors; correct as needed)
- % make depend (watch for any 'red' errors; correct as needed)
- % make
- % sudo -E make install
